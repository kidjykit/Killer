# Killer — คิลเลอร์เกม

เว็บแอปสำหรับเล่นเกมปาร์ตี้แนวจิตวิทยา **Killer** ตามกติกาใน [`rule.md`](./rule.md)
เล่นได้ทั้ง **ออนไลน์** (สร้างห้อง แชร์ลิงก์ให้เพื่อน) และ **ออฟไลน์** (ใช้มือถือเครื่องเดียวแทนสำรับไพ่)
ภาษาไทยทั้งหมด ธีมขาว–ดำสลับตามกลางวัน/กลางคืน

## สถานะของแต่ละส่วน

| ส่วน | สถานะ |
| --- | --- |
| ห้องออนไลน์ + แชร์ลิงก์ + realtime | ✅ ใช้งานได้ |
| flow เกมครบตาม rule.md (กลางคืน → กลางวัน → อภิปราย → โหวต) | ✅ ใช้งานได้ |
| กลางคืนแบบทุกบทบาทเลือกพร้อมกัน (ไม่ต้องรอเรียกทีละคน) | ✅ ใช้งานได้ |
| โหมดพิธีกร: คนจริง / ระบบอัตโนมัติ (เลือกตอนสร้างห้อง) | ✅ ใช้งานได้ |

## สแตก

- **Frontend** — React 18 + TypeScript + Vite + React Router (ไม่มี UI framework, CSS เขียนเอง)
- **Backend** — Cloudflare Workers + **Durable Objects** (1 ห้อง = 1 Durable Object) ผ่าน WebSocket
- **Deploy** — Cloudflare Workers พร้อม static assets (ไฟล์เดียวจบ ไม่ต้องแยก Pages)
- **Test** — Vitest ทดสอบ game engine ที่เป็น pure function

Durable Objects ที่ใช้เป็นแบบ **SQLite-backed** ซึ่งใช้ได้ทั้งแผนฟรีและแผนเสียเงินของ Cloudflare

## รันในเครื่อง

ต้องเปิด 2 เทอร์มินัล เพราะ Vite ทำหน้า UI ส่วน Worker ทำ API/WebSocket

```bash
npm install

# เทอร์มินัลที่ 1 — Worker + Durable Object (port 8787)
npm run cf:dev

# เทอร์มินัลที่ 2 — Vite dev server (proxy /api ไปที่ 8787)
npm run dev
```

หรือจะรันแบบ production ในเครื่องเลยก็ได้ (Worker เสิร์ฟทั้ง UI และ API จากพอร์ตเดียว):

```bash
npm run build && npm run cf:dev   # เปิด http://127.0.0.1:8787
```

คำสั่งอื่น ๆ

```bash
npm test         # รันเทสต์ game engine
npx tsc -b       # typecheck ทั้ง client และ worker
npm run build    # build UI ลง dist/
```

## Deploy ขึ้น Cloudflare

โปรเจกต์นี้ deploy เป็น **Cloudflare Worker** (ไม่ใช่ Cloudflare Pages) โดย Worker ตัวเดียว
เสิร์ฟทั้งหน้าเว็บและ API/WebSocket

```bash
npx wrangler login
npm run cf:deploy       # = wrangler deploy (build ตัว UI ให้เองผ่าน [build] ใน wrangler.toml)
```

`wrangler.toml` ตั้งค่าไว้ครบแล้ว — build hook, Durable Object binding, migration และ SPA fallback
ครั้งแรกที่ deploy Cloudflare จะสร้าง Durable Object namespace ให้เอง

### Deploy อัตโนมัติจาก GitHub

ถ้าอยากให้ push แล้ว deploy เอง ให้ใช้ **Workers Builds** (Cloudflare dashboard → Compute (Workers)
→ เลือก Worker → Settings → Builds → Connect a repository) ตั้งค่าเป็น

| ช่อง | ค่า |
| --- | --- |
| Build command | `npm run build` (หรือเว้นว่างก็ได้ เพราะ `[build]` ใน `wrangler.toml` รันให้อยู่แล้ว) |
| Deploy command | `npx wrangler deploy` |
| Root directory | `/` |

> ⚠️ **อย่าต่อ repo นี้เข้ากับ Cloudflare Pages** — Pages ไม่รองรับ Durable Objects และไม่อ่าน
> `[durable_objects]` / `[assets]` ใน `wrangler.toml` แบบนี้ ถ้าเผลอสร้างเป็น Pages project ไว้
> ให้ลบทิ้งแล้วสร้างใหม่เป็น Worker

### แก้ปัญหา deploy ไม่ผ่าน

| ข้อความ error | สาเหตุและวิธีแก้ |
| --- | --- |
| `The directory specified by the "assets.directory" field ... does not exist` | ยังไม่ได้ build ตัว UI — ปกติ `[build]` ใน `wrangler.toml` จัดการให้แล้ว ถ้ายังเจอให้รัน `npm run build` ก่อนแล้วค่อย `npx wrangler deploy` |
| `Authentication error` / `code: 10000` | ยังไม่ได้ล็อกอิน รัน `npx wrangler login` หรือถ้า deploy จาก CI ให้ตั้ง `CLOUDFLARE_API_TOKEN` และ `CLOUDFLARE_ACCOUNT_ID` โดย token ต้องมีสิทธิ์ **Workers Scripts: Edit** |
| `More than one account available` | ตั้ง `CLOUDFLARE_ACCOUNT_ID` หรือเพิ่ม `account_id = "..."` ใน `wrangler.toml` |
| `Durable Objects` ... `not enabled` / `code: 10084` | บัญชียังไม่ได้เปิดใช้ Workers เข้า dashboard → Compute (Workers) แล้วกดเริ่มใช้งานสักครั้งก่อน (Durable Object แบบ SQLite ที่โปรเจกต์นี้ใช้ อยู่ในแผนฟรี) |
| `Cannot apply new-sqlite-class migration to class ... that is already depended on` | เคย deploy ด้วย migration แบบ `new_classes` มาก่อน ให้ลบ Worker เดิมทิ้งแล้ว deploy ใหม่ |
| `workers.dev subdomain` ... `not found` | ยังไม่เคยตั้ง subdomain เข้า dashboard → Workers & Pages → ตั้ง workers.dev subdomain ก่อน |
| build ล้มที่ `tsc` หรือ `vite` | รัน `npm ci && npm run build` ในเครื่องเพื่อดู error เต็ม ๆ (ตรวจแล้วว่า clean checkout build ผ่าน ทั้ง wrangler 3 และ 4) |

## วิธีเล่นออนไลน์

1. กด **สร้างห้องใหม่** → ได้รหัสห้อง 5 ตัว เช่น `K7M2Q`
2. คัดลอกลิงก์ส่งให้เพื่อน ทุกคนใส่ชื่อเล่นแล้วเข้าห้องเดียวกัน
3. เจ้าของห้องตั้งกติกาในล็อบบี้ แล้วกด **เริ่มเกม — แจกไพ่**
4. ทุกคนแตะกองไพ่กลางโต๊ะเพื่อจั่วการ์ดของตัวเอง (การ์ดพลิกโชว์เฉพาะเจ้าตัว)
5. พิธีกรกด **เข้าสู่คืนที่ 1** — Killer ตำรวจ แม่ชี และโจร **เลือกเป้าหมายพร้อมกันได้เลย** ไม่ต้องรอเรียกทีละบทบาท
6. ตอนกลางวันแอปประกาศผล → อภิปราย → โหวต → วนไปจนจบเกม

### โหมดพิธีกร

- **คนจริงเป็นพิธีกร** (ค่าเริ่มต้น) — พิธีกรไม่ได้รับไพ่ เห็นบทบาททุกคนบนโต๊ะ เห็นสถานะว่าใครกดแล้ว
  และเป็นคนกดเดินเกมเอง ได้ **สมุดบันทึกพิธีกร** ที่สรุปทุกคืนให้ครบ
- **ระบบเป็นพิธีกรอัตโนมัติ** — ทุกคนได้รับไพ่และได้เล่น แอปนับเวลา เรียกบทบาท คำนวณผล และประกาศเอง
  ไม่มีใครเห็นบทบาทคนอื่นเลย

### กลางคืนแบบเลือกพร้อมกัน

เวอร์ชันบนเว็บไม่ได้เรียกบทบาททีละคนเหมือนเล่นกับไพ่จริง แต่เปิดกลางคืนเป็น **ช่วงเดียว**
แล้วให้ Killer ตำรวจ แม่ชี และโจร กดเลือกเป้าหมายของตัวเองพร้อมกันภายในเวลาชุดเดียว
(ตั้งค่าได้ในล็อบบี้ ค่าเริ่มต้น 45 วินาที) ทำให้เกมเร็วขึ้นมากและไม่มีใครต้องนั่งรอคิว

- **Killer / แม่ชี / โจร** เปลี่ยนใจได้จนกว่าจะหมดเวลา
- **ตำรวจ สืบได้รอบละ 1 ครั้งเท่านั้น** กดแล้วล็อกทันที เพราะได้คำตอบ "ใช่/ไม่ใช่" กลับมาเลย
  ถ้าเปลี่ยนใจได้จะกลายเป็นไล่สแกนทุกคนในคืนเดียว
- พิธีกร (โหมดคนจริง) เห็นแผงสถานะว่าใครกดแล้ว/ยังไม่กด และกด **จบกลางคืน** เมื่อพร้อม
  ไม่ต้องรอให้หมดเวลา

ส่วนกติกาในไฟล์ `rule.md` และตารางสรุปสำหรับพิมพ์ยังเป็นแบบเรียกทีละบทบาท
ซึ่งถูกต้องสำหรับการเล่นกับไพ่จริงที่ทุกคนนั่งอยู่ในห้องเดียวกัน

### สมุดบันทึกพิธีกร

จบทุกคืนแอปจะสรุปให้พิธีกรอ่าน พิธีกรไม่ต้องจำเอง เช่น

```
🌙 สรุปคืนที่ 1
  🔪 Killer เลือกฆ่า: เอ
  🔍 ตำรวจสืบ: อี → ชี้ถูก! คนนี้คือ Killer
  🕯️ แม่ชีรักษา: เอ → ❌ เป็นโมฆะ เพราะแม่ชีศีลขาด
  🥷 โจรปี้: ดี → ⚠️ โดนตัวแม่ชี! แม่ชีศีลขาด รักษาไม่ขึ้นทั้งคืน
  📣 ผลสรุป: คืนนี้ เอ เสียชีวิต
```

## เสียงและดนตรีประกอบ

เสียงทั้งหมด **สังเคราะห์สดด้วย Web Audio API** ไม่มีไฟล์เพลงแนบเลย — ไม่มีปัญหาลิขสิทธิ์
ไม่เพิ่มขนาดไฟล์ที่ต้องโหลด (โค้ดเสียงทั้งหมด ~3 KB gzip) และทำงานได้แม้เน็ตช้า
ทุกเสียงอยู่ในบันไดเสียง A minor เดียวกัน จะได้ฟังเป็นดนตรีชุดเดียวไม่ใช่เสียง beep มั่ว ๆ

| จังหวะในเกม | เสียงที่ได้ยิน |
| --- | --- |
| เริ่มเกม (แจกไพ่) | อาร์เพจจิโอไต่ขึ้นแล้วลงคอร์ด A minor |
| จั่วไพ่ของตัวเอง | เสียงไพ่รูดเบา ๆ |
| เข้าสู่กลางคืน | เสียงทุ้มไถ่ลง + ลมหวีด |
| ตลอดกลางคืน | โดรนทุ้มเพี้ยนกันเล็กน้อย + เสียงหัวใจเต้นทุก 2.4 วิ |
| เช้าแล้ว | คอร์ดสว่างไต่ขึ้น ตามด้วยเสียงคนตาย (หรือเสียงโล่งอกถ้าไม่มีใครตาย) |
| ตลอดกลางวัน | แพดอุ่น ๆ เบา ๆ |
| ช่วงโหวต | หัวใจเต้นเร็วขึ้นเป็นทุก 1.1 วิ เร่งความกดดัน |
| ถูกโหวตออก | เสียงกระแทกทุ้ม |
| จบเกม | คอร์ดเมเจอร์ถ้าประชาชนชนะ / ไมเนอร์ทุ้มถ้า Killer ชนะ |

มีปุ่ม 🔊 กับแถบปรับความดังที่มุมขวาบนของห้อง (และในหน้าออฟไลน์) จำค่าไว้ในเครื่องผู้ใช้
ปิดเสียงแล้วเพลงคลอจะหยุดสนิท ไม่กิน CPU ค้างไว้

เบราว์เซอร์ห้ามเล่นเสียงก่อนผู้ใช้แตะจอ แอปจึงปลดล็อกเสียงตอนกดปุ่ม "เข้าห้อง" / "สร้างห้อง" /
"สับไพ่และแจก" และมีตัวสำรองที่ปลดล็อกจากการแตะครั้งแรกที่ไหนก็ได้

**อยากใช้เพลงจริงแทน?** แก้ที่ `src/client/audio/GameAudio.ts` ไฟล์เดียว — วางไฟล์ใน `public/audio/`
แล้วเปลี่ยน `play()` กับ `setAmbience()` ให้เล่นไฟล์ ส่วนที่เหลือของแอปไม่ต้องแก้เลย

## ความเป็นส่วนตัวตอนกลางคืน

ตอนกลางคืนแอปตั้งใจ "ปิดตา" ผู้เล่นให้เหมือนหลับตาจริง ๆ

- ผู้เล่นทั่วไป **ไม่ได้รับข้อมูลลับตั้งแต่ชั้น server** ไม่ใช่แค่ซ่อนใน UI — บทบาทของคนอื่น
  สมุดบันทึกพิธีกร ตัวเลือกของ Killer และผลการสืบของตำรวจ ถูกกรองออกใน `viewFor()` ก่อนส่ง
- ซ่อนไฟสถานะออนไลน์ของผู้เล่นทุกคน เหลือแค่พิธีกรที่เห็น เพื่อไม่ให้เดาได้ว่าใครกำลังทำอะไร
- ห้ามพิมพ์ในห้องแชทหลักตอนกลางคืน
- โหมดอัตโนมัติจะเดินครบเวลากลางคืนเสมอ **ไม่ตัดจบเร็วแม้ทุกคนกดครบแล้ว** เพราะความเร็วในการจบคืน
  จะกลายเป็นเบาะแสว่ามีบทบาทไหนตายไปบ้าง

เมื่อเพิ่มวิดีโอ/เสียงเข้ามา จุดนี้จะขยายเป็นการ **บังคับ mute และปิดกล้องทุกคนตอนกลางคืน**
(เลือกไว้แล้วตอนออกแบบ) เหลือเฉพาะพิธีกรที่เห็นสถานะ

## โหมดออฟไลน์

- **แจกการ์ด** (`/offline`) — ใส่ชื่อผู้เล่น สับไพ่ แล้วส่งมือถือต่อกันไปทีละคน
  แต่ละคนแตะเปิดดูไพ่ของตัวเอง อ่านหน้าที่ แล้วกดปิดก่อนส่งต่อ มีหน้า "เฉลยทั้งหมด" สำหรับพิธีกรแยกต่างหาก
- **ตารางสรุป 1 หน้า** (`/print`) — A4 แนวตั้ง พิมพ์หรือบันทึกเป็น PDF ได้จากเบราว์เซอร์
  มีครบทั้งตารางบทบาท จำนวนไพ่ 6–12 คน บทพิธีกร ตารางคิดผลกลางคืน เงื่อนไขชนะ และมารยาทการเล่น
